# J280 LAB4 R1 本地工程


## 本地适配

- `src/pins.cst` 和 `02_Pins_Wiring/pins.cst` 按本机 J280 原理图改为 `BN1=AA17`、`BN2=V15`；`src/pendulum_v6_top.v` 交换 B 通道方向输出，以保持 R1 原本的实际电机驱动方向。
- `src/lab_telemetry.v` 为遥测帧添加寄存器；`src/swing_reference_bridge.v` 为运行时速度上限、PWM 上限、软行程和诊断动作码添加寄存器；`src/pendulum_v6_top.v` 为遥测动作码、电机指令及控制使能添加寄存器。电机引脚仍由原始安全条件直接关断。这些改变用于满足板载 50 MHz 时序，不改变控制参数或起摆状态机。
- `src/motor_signed_pwm.v` 调整计数器控制路径，保持原有 PWM 脉冲宽度及反转空白期；`05_Simulation/tb_auto_motor_ports.v` 更新为原理图引脚名下的方向断言。

## 操作和调参

1. 使用 `03_PC_Monitor/SwingLab4_R6.exe` 或 `06_Host_Source/swing_lab.py` 连接双向串口，115200 波特率；本版 K1 启动需要电脑持续发送心跳。
2. 停机时扶摆杆直立并保持静止，按 K3 标定。K3 不启动电机。
3. 放下摆杆，待自然下垂停稳后按 K1 开始自动起摆。K2 停止，K4 急停。
4. R6 上位机可实时调摆杆内环 P/I/D 和位置外环 P/I/D，并在同一窗口显示两环目标与实际曲线；完整曲线需配套 R6 位流。输入后点击对应发送按钮并等待 ACK。

## 位置扩展

- 直立平衡接管时记录横杆编码器位置为目标 0；电脑键盘或界面发送相对目标 -180..+180 计数、最大速度 1..30 计数/秒。
- FPGA 将目标按加减速轨迹逐步移动，外环把位置误差变成摆杆目标角，内环继续稳定摆杆。原 K2/K4、角度和行程停机保护保留。
- 2026-10-31 R2：实测新位置指令 ACK1、轨迹目标确实移动；10 计数约为 3°，肉眼不明显。原外环 P=4/256 ADC/计数造成大目标长期跟踪误差，现将板顶层改为 12/256，外环目标角上限仍为 ±6 ADC。连续发送相同目标不再重启轨迹速度。
- 本轮请配套使用 `release/J280_R6_PID_target_actual_curves_20261101.fs` 与 `03_PC_Monitor/SwingLab4_R6.exe`。先关闭旧上位机和串口助手，再打开 R6。旧版文件保留作回退。
- R4 的 P/I/D 实时输入在 `06_Host_Source/swing_lab.py`。R4 使用 opcode6 一次下发三个增益，遥测版本63；R3 使用 opcode5，只能调 P/D。编译默认 P=12(Q8)、I=0(Q16)、D=1790(Q8)。P=0..32，I=0..64，D=0..2048，均输入原始整数。点击“发送外环 P/I/D”并收到板端 ACK 才视为本次会话生效；断电或 K5 复位恢复默认。外环 I 的累计修正限幅 ±1 ADC，总角度修正限幅 ±6 ADC。
- R5 遥测版本64，增加 opcode7 内环 P/I/D 一次下发。默认内环 P=220、I=0、D=400；UI 中 I 是小数 0..0.5，板端存储值为显示值×256。例如 0.25 对应 64。每次修改内环或外环增益会清零对应积分历史；现有停机保护保留。当前协议只有 ACK，没有独立增益回读。
- R6 遥测版本65：直立平衡期间字节20..21给出**内环目标摆杆角**（半ADC码），字节12..13是实测角；字节14..17是横杆实测位置，字节60..61是当前轨迹目标与实测之间的误差。界面把两组目标/实际分别叠画，并在停机后保留最近一次曲线。新 CSV 增加 `inner_angle_target_adc` 和 `outer_position_target_counts`。
- 重新下载本轮 `impl/pnr/swing_lab.fs`。让装置进入“直立平衡”后，先发送 `+30`、速度 `10` 计数/秒，等待至少 5 秒，观察编码器、轨迹目标、位置误差；不要连续点击同一目标。然后发送 0 返回接管点。若平衡本身不能持续，位置移动无法保证摆杆不倒。

本机 Gowin V1.9.12.03 的 R6 位流在 `impl/pnr/swing_lab.fs`，另存于 `release/J280_R6_PID_target_actual_curves_20261101.fs`。旧位流仍在 `release`。首次上电测试请保持 K2/K4 可立即操作，并保留横杆运行空间。

## 2026-11-01 R7 更新

当前 `impl/pnr/swing_lab.fs` 已是 R7，发布副本为 `release/J280_R7_outer_soft_window_20261101.fs`；配套界面为 `03_PC_Monitor/SwingLab4_R7_soft_window.exe`。R6 发布文件仍可回退。R7 协议仍为 0x65，目标位置命令仍允许 -180～+180 计数，界面的单次移动步长仍独立限制为 1～30 计数。

R7 将外环目标角修正上限由 ±6 调为 ±8 ADC，每 5 ms 的最大改变量由 14/256 调为 32/256 ADC。上电默认外环 P=17、I=0、D=400，内环沿用最后一次板端 ACK 的 P=165、I=0、D=315。围绕**当前轨迹目标**设置位置软窗口：误差超过 6 计数后，额外按 128/256 ADC/计数逐步增加回中目标角，仍受总修正 ±8 ADC 限制。位置目标改变时软窗口随轨迹移动。软窗口优先保留摆杆平衡，不能保证横杆绝不越过 ±10 计数；K2/K4、角度和原行程停机保护不变。

R7 已通过 `tb_position_move`、`tb_position_soft_guard`、`tb_auto_motor_ports`、`tb_reference_top`、`tb_lab_config` 仿真，以及高云综合、布局布线和 50 MHz 时序检查（setup/hold 违例端点 0/0）。尚未在实体板验证稳定效果。下载 R7 后先关闭旧上位机再运行 R7 界面；板子复位会丢失先前在线下发的内外环 PID，输入框编辑值也不等于板端生效值，须以 ACK 为准。

## 2026-11-01 R8 更新

下载 `release/J280_R8_gradual_position_20261101.fs`，配套 `03_PC_Monitor/SwingLab4_R8_gradual_position.exe`。R7 实测目标位置固定 -17 计数时，实测位置在 -90～+240 计数之间变化；原软边界约 20 计数误差就把目标角修正推至 ±8 ADC 上限。R8 保持目标位置范围和原有安全保护，将软边界起点移至误差 10 计数，并将额外回中斜率改为 32/256 ADC/计数。目标角修正从 4 ADC 以上按一半斜率压缩，最大仍是 ±8 ADC。P17/D0 时约 70 计数误差才达到总上限；D 运行时可能更早触限。

此版通过 `tb_position_soft_guard`、`tb_position_move`、`tb_auto_motor_ports`、`tb_reference_top`、`tb_lab_config` 仿真及 UI 演示测试；Gowin 布局布线 Fmax 50.795 MHz，50 MHz setup/hold 违例端点 0/0。尚未做实体稳定性验证。请先用默认 P17/I0/D400、内环 P165/I0/D315 完成一轮不碰摆杆、不在运行中改参的短测，再看目标/实际位置曲线。

## R8 放大曲线界面

`03_PC_Monitor/SwingLab4_R8_large_chart.exe` 保持 R8 位流和串口协议不变，在主界面新增“放大曲线（独立窗口）”。独立窗口可拖动缩放，可看两条曲线或单独看摆杆角、横杆位置；青色为实测，黄色为目标。只有板端 ACK 确认后的 PID 改动才会在曲线上出现竖线：紫色为内环，绿色为外环。关闭独立曲线窗口不会断开串口。曲线仍只保留当前或最近一次平衡段、最多约 60 秒的数据；CSV 继续保存完整记录。UI 演示测试已覆盖放大窗口、单曲线模式和标记绘制。

## R9 内环隔离修正

R8 的软位置边界在外环 P/I/D 全为 0 时仍输出目标角修正，因此之前“把外环全设 0 就能隔离内环”的操作说明不准确。R9 在全零外环增益时禁止这项软边界；任一外环增益非零后恢复 R8 的位置修正。角度、行程、K2/K4 等保护仍有效，目标位置发送范围不变。位流为 `release/J280_R9_true_inner_only_20261101.fs`，界面为 `03_PC_Monitor/SwingLab4_R9_inner_only_tuning.exe`。通过 `tb_inner_only_guard_off`、`tb_position_soft_guard`、`tb_position_move`、`tb_auto_motor_ports`、`tb_reference_top`、`tb_lab_config` 仿真和 UI 测试；Gowin 50 MHz 时序 Fmax 50.166 MHz、setup/hold 违例端点 0/0。实体平衡效果尚待验证。

## R11 暂时关闭横杆行程限位停机

R11 只关闭横杆超过 448 编码器计数时的硬行程停机及其电机输出门控。摆杆角度偏离、传感器故障、K2 停止和 K4 急停保持有效；位置软边界、起摆阶段减速以及位置目标指令的 -180～+180 范围也保留。该修改不会保证横杆停在某个位置。

位流为 `release/J280_R11_no_arm_travel_stop_20261101.fs`，界面为 `03_PC_Monitor/SwingLab4_R11_no_arm_stop.exe`。R10 上电默认 PID 不变：外环 15/34/1500，内环 115/(72/256)/520。`tb_hard_travel_disabled` 验证关闭硬行程停机后越过 448 计数仍运行，而 K2/K4 仍会停机；既有仿真与 UI 测试通过。Gowin Fmax 50.868 MHz，50 MHz setup/hold 违例端点 0/0。尚未进行实体板验证；须下载 R11 位流，单独更新上位机不会改变板端限位逻辑。

### R11 自动在线调 PID 界面

新版上位机为 `03_PC_Monitor/SwingLab4_R11_live_PID.exe`，与同一份 R11 位流配套，不需要重新综合或下载。默认勾选自动在线下发；修改内环或外环 P/I/D 后，停止输入约 250 ms 才发送最后一组有效值，并等待同序号 ACK。连续编辑会合并，手动发送后不会因延时再重复发送相同值；板端拒绝或超时会显示结果，不自动反复重发。取消勾选后恢复手动发送。运行中在线调参会清除该环积分历史，因此不要持续快速来回改值。`test_live_pid_auto.py` 验证连续改值合并、双环 ACK、无重复下发；源码和打包程序的演示验证通过。

## R12 外环 D 扩展到 4095

外环 D 在线输入与板端 opcode 5/6 的接受范围由 0～2048 扩大为 0～4095。板端仍用 12 位无符号 D 输入，位置环控制公式与 ±8 ADC 目标角修正上限不变；上电默认外环 D=1500，其他 PID 默认值也不变。R11 的横杆硬行程停机关闭、摆杆角度与 K2/K4 保护均保留。位流 `release/J280_R12_outer_D_4095_20261101.fs` 与上位机 `03_PC_Monitor/SwingLab4_R12_outer_D_4095.exe` 必须配套使用；旧位流可能把大于 2048 的命令拒绝为 ACK3。`tb_lab_config` 验证 4095 接受与 4096 拒绝，`tb_outer_d_extended` 验证 4095 在控制器中不截断，打包上位机演示验证通过。Gowin Fmax 51.837 MHz，50 MHz setup/hold 违例端点 0/0；实体板尚未验证。

## R13 外环 D 扩展到 8191

外环 D 在线范围由 0～4095 扩为 0～8191，板端改为读取 13 位增益。默认外环 D=1500，其余 PID 默认、R11 关闭的横杆硬行程停机、摆杆角度与 K2/K4 停机均未改变。位流 `release/J280_R13_outer_D_8191_20261101.fs`，上位机 `03_PC_Monitor/SwingLab4_R13_outer_D_8191.exe`。超过 4095 时必须配套下载 R13 位流；旧位流会拒绝新范围。`tb_lab_config` 验证 8191 接受、8192 拒绝；`tb_outer_d_extended` 验证 8191 不截断且阻尼项大于 2048 时；打包上位机演示验证通过。Gowin Fmax 51.647 MHz，50 MHz setup/hold 违例端点 0/0。控制目标角修正仍限幅 ±8 ADC，增大 D 到更高值未必改善实际平衡；实体板尚未验证。

### R14 上位机正弦横杆轨迹
